# F-22 Raptor Engineering Experience ✈️

A scrollytelling landing page showcasing the F-22 Raptor's fifth-generation engineering, stealth capabilities, avionics, propulsion, and concealed armament through a scroll-linked image sequence animation.

## 🚀 Features

- **Scroll-Linked Animation**: 168-frame canvas rendering synchronized with scroll progress via Framer Motion.
- **Buttery Smooth Interpolation**: Spring physics (`useSpring`) for jitter-free animation scrubbing.
- **Luxury Minimal Aesthetic**: True `#050505` black background for seamless void blending and crisp modern typography.
- **Glassmorphic Navigation**: Full-screen slide-down menu with staggered micro-animations.
- **HUD-style Loader**: Aviation-themed preloader ensuring all frames load prior to interaction.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14 (App Router)](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Rendering**: HTML5 2D Canvas
- **Icons**: [Lucide React](https://lucide.dev/)

## 🏁 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
